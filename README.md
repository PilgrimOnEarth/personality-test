# personality-test

교육·모임용 64유형 성격유형검사 (100문항, 6개 지표). 파일 하나(`index.html`)로 동작하며 응답은 저장되지 않습니다.

- 주소: https://pilgrimonearth.github.io/personality-test/
- 배포: Settings → Pages → Source `Deploy from a branch`, Branch `main` / `(root)`
- 문항·유형 설명 수정: `index.html`의 `RAW`(문항), `TYPES`(유형 리포트) 목록

교육과 자기이해를 위한 참고 도구이며 표준화된 심리검사가 아닙니다. MBTI® 공식 검사와 관련이 없습니다.
